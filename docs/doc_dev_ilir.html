dev_ilir

Base fed-back common-gate dev_ilir design, rebiased to VBIAS_CG=1.0V, targeting 2.4 GHz.

Functional

Design

Three-stage LNA core: a common-gate (CG) input stage (M2, actively source-degenerated by current-sink M5) feeds a cascoded common-source (CS) gain stage (M1/M4), with a source-follower buffer (M3) and a separate CS noise-cancellation branch (M9) summed at the output. This is the original IlirShala1 dev_ilir topology (PR #15), later rebiased by EngGhaith (PR #17, VBIAS_CG 2.2V -> 1.0V) to fix the CG stage's operating point.

  • IlirShala1 PR #15: introduces the CG+CS+buffer+noise-cancellation core topology, with buffer removed and matching adjusted for wideband operation (f1c11d6).
  • EngGhaith PR #17 (7fdbfc6): rebiases M2 (the CG input device) VBIAS_CG from 2.2V to 1.0V to correct its operating point.
  • No band retuning on this branch — this is the 2.4 GHz baseline that gnssl1/gnssl2/loraeu868 all retune from.
