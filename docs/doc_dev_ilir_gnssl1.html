dev_ilir_gnssl1

dev_ilir retuned to GNSS L1 (1575.42 MHz) using shunt-capacitor trimming only, no inductor/bias/topology changes.

Marginal

Design

Three-stage LNA core: a common-gate (CG) input stage (M2, actively source-degenerated by current-sink M5) feeds a cascoded common-source (CS) gain stage (M1/M4), with a source-follower buffer (M3) and a separate CS noise-cancellation branch (M9) summed at the output. This is the original IlirShala1 dev_ilir topology (PR #15), later rebiased by EngGhaith (PR #17, VBIAS_CG 2.2V -> 1.0V) to fix the CG stage's operating point. This branch relocates the passband to GNSS L1 by adding/trimming three shunt MIM caps.

  • Adds CTUNE_IN (rf_in_pad||vss), CTUNE_M2 (vm2||vdd), and CTUNE_OUT (vout_tank||vdd) shunt caps in parallel with the existing matching/tank elements (7340393).
  • Sizing anchored on the branch's own simulated S21 peak (2.437 GHz) via f ∝ 1/√(LC) scaling; explicitly a first-pass hand-calc, not re-simulated at commit time.
  • No inductor, bias, or topology changes relative to the rebiased dev_ilir base.
