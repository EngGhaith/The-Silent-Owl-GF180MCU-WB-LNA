dev_ghaith_loraeu868

dev_ghaith relocated to LoRa EU868 (868.30 MHz) via shunt-cap trim plus an enlarged series input-coupling cap.

Functional

Design

Same CG-degenerated cascode core as dev_ghaith. As with the GNSS L2 relocation, the lower frequency requires both a shunt-cap retune of the CG/output tanks and a substantially enlarged series AC-coupling cap C2 so it doesn't drop signal across its own growing reactance.

  • Shunt caps jointly trimmed: C5=0.5u, CTUNE_M2=32u, CTUNE_OUT=1u
  • Series input-coupling cap C2 extended 30.2u → 50.0u for the lower EU868 frequency
  • No inductor or topology changes
