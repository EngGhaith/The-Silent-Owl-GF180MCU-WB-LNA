Design Review: dev_ilir_pexmatched

A walkthrough of the branch's three design points — the adopted CG-tank baseline, a tested single-inductor input simplification, and a cascode experiment — each simulated against the real PEX-extracted pad netlist (same convention used across every topology in this project). All numbers below are at 2.4 GHz unless noted.

✓ Baseline (two-branch + CG-tank) — recommended ● Single-L — viable simplification, ~0.5 dB NF cost ✕ Cascode — not adopted

Design evolution

Step 1 · Adopted

Primary (two-branch input)

commit 68e4718

The CG input stage (M2) is matched with two separate branches — a shunt inductor+resistor (LSHUNT/Rs1) and a series match inductor (Lmatch) — plus the established LD4(8nH)/RLD3(30Ω) shunt-peaking load on the CG drain.

Best NF and widest match — the reference design (“ilir24”)
Step 2 · Tested

Single-L input

commit 6c00a85

LSHUNT and Lmatch merged into one equivalent inductor Leq, dropping one component from the input network while re-matching at 2.4 GHz against the same pad.

Simpler BOM, but S11 margin and NF both give up some ground
Step 3 · Exploratory

+ Cascode (M2C)

commit 7809891

A cascode device M2C stacked on M2's drain, gate tied to vdd (a free AC ground in this testbench). Motivation was better reverse isolation; S12 did improve substantially — isolation was never the bottleneck here.

M2C's channel noise injects directly at the shared output node — NF degrades, not recovered by resizing (see cascode report)

Recommendation

Ship the primary two-branch design; single-L is a fair fallback; cascode stays out.

The original two-branch input (LSHUNT/Rs1 + Lmatch) with the LD4/RLD3 CG-tank load remains the best-performing dev_ilir_pexmatched configuration against the real PEX pad: S11 ≈ −23.1 dB, S21 ≈ 18.0 dB, NF ≈ 2.49 dB at 2.4 GHz, with the widest matched bandwidth of the three (≈394 MHz, 16.8%).

  • Single-L is a legitimate component-count reduction if board/die area matters more than the last ~0.5 dB of NF and ~30 MHz of matched bandwidth — it's not a regression driven by a mistake, just a real one-inductor-for-performance trade.
  • Cascode was motivated by reverse isolation, which this design never lacked; the measured cost (NF 2.49→3.35 dB, S21 down ≈1.7 dB, matched BW down to ≈296 MHz) is a straight loss with no offsetting benefit on this topology. Full root-cause (DC operating-point noise analysis, sizing sweep, body-effect test) is in the companion CG Cascode Exploration report.
