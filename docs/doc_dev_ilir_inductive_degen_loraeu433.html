dev_ilir_inductive_degen_loraeu433

Attempted LoRa EU433 (433.92 MHz) relocation with LDEG/LD2/LD4 held fixed; confirmed structural failure (negative gain), matching the already-documented EU433 failure of this output-stage lineage.

Structural failure

Design

A structurally different lineage from plain dev_ilir: built on top of dev_ghaith_passive_output's output stage, this variant removes the CG input stage's active current-sink degeneration (M5) entirely and replaces it with a single passive degeneration inductor LDEG=12n from the CG source node to VSS — the classic inductively-degenerated CG/CS input-matching technique, where Zin's real part comes from gm·Ldeg/Cgs rather than from a biasing device. VBIAS_CG was rederived from scratch (2.20V -> 0.80V) since the bias point no longer inherits from M5's current-setting. This is NOT a band-retune of dev_ilir; it is a separate topology variant that happens to share the "dev_ilir" name prefix. This branch attempts to relocate the passband to LoRa EU433 using the same caps/R/bias-only methodology that worked for GNSS L1, L2, and LoRa EU868 on this variant — and fails.

  • Swept RLD3 down to 1Ω and CTUNE_M2 up to 25pF (61ecae1); the CG-stage tank gain crosses zero near 520-550MHz and goes negative for any CTUNE_M2 large enough to pull the peak further down.
  • Best achievable operating point: RLD3=1Ω, CTUNE_M2=16pF, giving S11=-0.41dB, S21=-7.42dB (negative gain), S22=-0.23dB, NF=9.72dB at 434MHz.
  • Mirrors the already-documented EU433 failure for dev_ghaith_passive_output (this variant's own output-stage ancestor) and for the original unmodified dev_ghaith, neither of which ever reached EU433 either.
  • This is a legitimate, confirmed structural limit of this output-stage lineage at EU433, not a tuning gap — consistent with the sibling dev_ghaith_lowtailnoise_loraeu433 branch's documented failure at the same band.
