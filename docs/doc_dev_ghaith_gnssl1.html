dev_ghaith_gnssl1

dev_ghaith relocated to GNSS L1 (1575.42 MHz) by resizing shunt tuning caps only — hand-calculated and never re-simulated until this archival pass.

Marginal

Design

Same CG-degenerated cascode core as dev_ghaith. The relocation resizes the existing input shunt cap C5 and adds two new shunt MIM caps (CTUNE_M2 at the M2/CG drain tank, CTUNE_OUT at the output tank) sized by f∝1/√(LC) scaling anchored on dev_ghaith's own simulated S21 peak. No inductor, bias, or topology changes were made.

  • C5 (input shunt match cap) resized in place — no new component added here
  • CTUNE_M2 added in parallel with RLD3/LD4 on the M2/CG drain tank
  • CTUNE_OUT added in parallel with RLD2/LD2 on the output tank
  • First-pass hand-calculated values only; commit explicitly flags these as not yet re-simulated
