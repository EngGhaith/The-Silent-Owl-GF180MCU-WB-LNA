dev_ghaith_lowtailnoise_gnssl2

lowtailnoise variant relocated to GNSS L2 (1227.60 MHz) via RLD3 reduction and a larger CTUNE_M2 shunt cap, inductors untouched.

Functional

Design

Same RF-choked/bypassed tail as dev_ghaith_lowtailnoise. Relocation follows the same caps/R/bias-only recipe as the GNSS L1 sibling, with a larger CTUNE_M2 for the lower frequency.

  • RLD3 lowered 30 → 2 Ω
  • CTUNE_M2 added, 0 → 1.4 pF shunt cap at vm2
  • LD2/LD4/LIN/LCHOKE inductors left untouched
