main_lowtailnoise_loraeu433

Attempts to relocate the lowtailnoise core to LoRa EU433 (433.92MHz) by sweeping C8 up to 350u; the vx tank gain peak only reaches the band after S21 has already crossed through zero — a confirmed structural failure, consistent with dev_ghaith_passive_output and dev_ilir_inductive_degen at the same band.

Structural failure

Design

This lineage starts from the same "no-cancellation core" described above and adds an RF choke plus a bypass capacitor across the common-gate (CG) stage's tail current source, shunting that source's noise to AC ground instead of letting it inject onto the signal path — the same low-tail-noise change that was later folded into current main. Band relocation on this lineage was done with caps/resistors/bias only; the LD2, LIN and LCHOKE inductors were left untouched from the 2.4GHz design.

  • Builds on the no-cancellation core (CG input + CS gain + cascodes + source-follower buffer) by adding an RF choke + bypass cap across the CG stage's tail current source.
  • RF-choke/bypass change cuts the CG tail's noise contribution — the same technique later adopted into current main.
  • Band relocation restricted to passives, resistors and bias (primarily the vx tank cap C8); LD2/LIN/LCHOKE inductors untouched.
  • Still predates all of main's PEX-pad-matching work — simulated here against the idealized PDK pad, as this family always was.
