dev_ghaith_passive_output_loraeu433

Attempted LoRa EU433 (433.92 MHz) relocation of the passive-output variant; confirmed structurally unreachable with positive gain under the caps/R/bias-only constraint.

Structural failure

Design

Same L-match output as dev_ghaith_passive_output. An earlier relocation attempt resized LD2/LD4 directly, which violates the project rule that inductors must stay fixed across bands; that was reverted and replaced with an RLD3/CTUNE_M2-only attempt, which still cannot reach positive gain at this band.

  • Earlier LD2/LD4-resizing attempt reverted for violating the fixed-inductor-across-bands rule
  • LD2/LD4 and C2/C11 restored to native 2.4GHz values
  • RLD3 lowered 30 → 2Ω and CTUNE_M2 (16pF) added at vm2 to try to pull the CG-stage tank resonance down
  • Best achievable point at 434MHz still shows negative gain; commit confirms the band is structurally unreachable under the caps/R/bias-only constraint, consistent with the original dev_ghaith's own documented EU433 failure
