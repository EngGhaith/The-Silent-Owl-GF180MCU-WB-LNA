dev_ilir_inductive_degen

Replaces dev_ilir's active CG-stage degeneration (current-sink M5) with a single passive degeneration inductor LDEG=12n; built on dev_ghaith_passive_output's output stage, not on dev_ilir.

Functional

Design

A structurally different lineage from plain dev_ilir: built on top of dev_ghaith_passive_output's output stage, this variant removes the CG input stage's active current-sink degeneration (M5) entirely and replaces it with a single passive degeneration inductor LDEG=12n from the CG source node to VSS — the classic inductively-degenerated CG/CS input-matching technique, where Zin's real part comes from gm·Ldeg/Cgs rather than from a biasing device. VBIAS_CG was rederived from scratch (2.20V -> 0.80V) since the bias point no longer inherits from M5's current-setting. This is NOT a band-retune of dev_ilir; it is a separate topology variant that happens to share the "dev_ilir" name prefix.

  • Removes M5 (active current-sink degenerating the CG input stage's source) and adds LDEG=12n from the CG source node (s) to VSS (05107ff).
  • Rederives VBIAS_CG from scratch (2.20V -> 0.80V) since the operating point no longer inherits from M5's current-setting; lands M2 at ~3.0mA, gm/Id~9.3/V.
  • Rebuilds the input coupling/shunt caps around the new source impedance: C2 (series) 30.2168u -> 25u, C5 (shunt) 10u -> 15u.
  • Built on f80a3fa's tuned passive L-match output network (itself replacing dev_ghaith's output coupling) — this entire lineage is distinct from the dev_ilir/IlirShala1 CG+CS+NC topology above.
  • Reported unconditionally stable (K_min ~120, μ/μ' > 1 everywhere) with ~21% lower PDC than the fed-back dev_ilir baseline.
