dev_ghaith_passive_output

dev_ghaith with the output coupling replaced by a deliberate 2-element passive L-match network (LD2 + C11) instead of a single fixed coupling cap, still at 2.4 GHz.

Functional

Design

Same CG-degenerated cascode core as dev_ghaith, but the output no longer rides on whatever match the drain tank happens to provide. The cascode drain (vx) couples to rf_out_pad through LD2 and C11 retuned jointly as a 2-element L-match, per a request to use passive R/L/C matching rather than an output buffer.

  • LD2 retuned 4n → 7.0n and coupling cap C11 retuned 4p → 0.8p as a joint L-match at 2.4GHz
  • VBIAS_CAS raised 3.70V → 4.80V for extra matching headroom at modest current cost
  • Reported unconditionally stable (K_min≈91.5, μ/μ′ > 1 everywhere), 0.32dB gain ripple across 2.3-2.5GHz
