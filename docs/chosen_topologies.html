Overview

BW = the contiguous frequency span around the design point where S11 ≤ −10dB, S22 ≤ −10dB and S21 ≥ 10dB all hold at once — shaded on each chart below. Narrow by design: each match resonantly cancels the pad's fixed parasitic capacitance at one frequency, which caps achievable bandwidth×depth (a Bode–Fano-type limit) regardless of network complexity.
