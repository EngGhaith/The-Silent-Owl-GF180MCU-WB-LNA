main_gnssl2

Relocates the no-cancellation core to GNSS L2 (1227.60MHz) by retuning C8 (12.64u→30.0u), then enlarging C2 and C3 to recover match.

Marginal

Design

This is the "no-cancellation core": common-gate (CG) input stage feeding a common-source (CS) main gain device, both cascoded, with a source-follower output buffer, biased from an on-chip resistor-ladder bias network. It replaced an earlier main topology that also carried an auxiliary noise-cancellation path (M7, M9, C7, C10, R6, R3); an A/B test on that lineage measured zero NF benefit from the cancellation path while it loaded nodes vx and s with extra parasitics and drew current, so it was dropped and the remaining core was re-optimized from scratch. This branch relocates that re-optimized core to a new target band by retuning passives and bias, without touching main's later RF-choke/bypass or PEX-matching work.

  • Common-gate (CG) input device + common-source (CS) gain device, both cascoded, with a source-follower output buffer.
  • Noise-cancellation path (M7, M9, C7, C10, R6, R3) already removed relative to the earlier main lineage; bias and passives re-optimized from scratch after removal.
  • Band relocation done via the output/vx tank cap (C8) plus, in this branch, follow-up enlargement of the input coupling cap C2 and output coupling cap C3 to recover S11/S22 match that the retune disturbed.
  • Predates both main's RF-choke/bypass CG-tail noise reduction and all PEX-pad-matching work.

History

This no-cancellation core is an earlier iteration of the topology at the heart of today's main: it already dropped the auxiliary noise-cancellation path (M7/M9/C7/C10/R6/R3) that an A/B test showed gave zero NF benefit, but it predates main's later RF-choke/bypass CG-tail noise reduction and all of the current PEX-pad-matching and bias-optimization work. Re-simulated here with the idealized PDK pad model, matching this family's original (pre-PEX) sign-off methodology.
